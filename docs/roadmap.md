# 個人網站開發方向

更新日期：2026-10-12。

## 定位

- **主要讀者：**朋友與有興趣的訪客；網站以個人紀錄為主。
- **次要讀者：**求職或招募方，只提供 About 頁的經歷摘要；完整履歷請對方來信索取，不公開 PDF。
- **語言：**繁體中文；英文版待評估，`/en/` 維持轉址到首頁。

## 網站結構

| 路徑                            | 內容                                       |
| ------------------------------- | ------------------------------------------ |
| `/`                             | 介紹、近況、服務、最新文章、精選專案、興趣 |
| `/posts/`、`/posts/tags/<tag>/` | 文章與標籤；RSS 在 `/rss.xml`              |
| `/now/`                         | 近況                                       |
| `/hobbies/`                     | 興趣專區：遊戲、攝影／旅行相簿             |
| `/projects/`                    | 專案案例：問題、角色、做法、成果           |
| `/services/`                    | 公開服務與即時狀態                         |
| `/about/`                       | 自我介紹、經歷摘要、聯絡方式               |

各頁內容的撰寫方式見 [writing.md](writing.md)。

## 設計

- Material UI 暗色主題，沿用暗灰背景與青綠色強調色；規範見 [AGENTS.md](../AGENTS.md#rules)。
- 所有頁面內容與頁首左緣對齊；首頁與列表頁用寬版，文章與關於我等閱讀頁限制欄寬，專案頁右側放資訊側欄。
- 文章一律以條列呈現（日期一欄、標題與摘要一欄），專案、興趣用卡片。
- 第二層以下的頁面在標題上方顯示上層頁面連結。
- 服務卡片右上角放「開啟服務」圖示按鈕，文章、專案、興趣整列或整張卡片可點，區分操作入口與閱讀入口。
- 手機版頁首只顯示圖示，五個導覽項目與它排在同一列，不收進選單，因此不需要 JavaScript。

## 後續方向

| 方向     | 內容                                       | 前提                       |
| -------- | ------------------------------------------ | -------------------------- |
| 內容填充 | 近況、經歷、兩個代表專案、興趣紀錄與相簿   | 由站主撰寫                 |
| 搜尋     | 文章站內搜尋                               | 文章累積到列表不好找時     |
| 互動展示 | 與專案相關的遊戲機制、演算法視覺化或小工具 | 開發與維護成本較高         |
| 服務狀態 | 連到既有的公開狀態頁                       | 有需求時；自建監測需要維運 |
| 英文版   | 主要頁面的英文翻譯                         | 確定有英文讀者時           |

## 範圍限制

- 維持靜態網站，只使用可公開的資料；其餘規範見 [AGENTS.md](../AGENTS.md#rules)。
- 留言、帳號、聯絡表單後端、即時外部元件與流量分析，等有明確需求再評估。
